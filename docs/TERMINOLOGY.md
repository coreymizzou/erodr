# Erodr Terminology

| Term | Historical meaning | Placement in reconstruction | Evidence |
| --- | --- | --- | --- |
| **erodr** | Lowercase-styled product name | Splash/login placeholder wordmark and project copy | Historical articles and app listing |
| **rodies** | Erodr users, pronounced “roadies” | Seed/profile/help copy where a user noun is needed | 2013 Silicon Prairie News profile |
| **Streamer** | Proximity-based stream of posts | Main Mizzou feed and primary bottom tab | 2013 profile; firsthand `1NFJTtrL.png` |
| **Classmates** | Later-era feed for validated students at the same school | Database compatibility enum and reconstruction history only | 2017 screenshot; 2014 release |
| **Anonymous Ticker** | Nationwide continuous stream of anonymous college posts | Cross-campus anonymous feed | 2014 release |
| **National Feed / National Posts** | Best attributed posts from validated students nationwide | Separate national feed | 2014 release / archived app description |
| **Popular** | Feed ordering/filter | Streamer selector | Firsthand `1NFJTtrL.png`; 2017 screenshot |
| **Recent** | Feed ordering/filter | Streamer selector; default in observed screenshot | Firsthand `1NFJTtrL.png`; 2017 screenshot |
| **Nearest** | Proximity ordering/filter | Streamer selector; simulated campus coordinates in demo | Firsthand `1NFJTtrL.png`; 2017 screenshot |
| **Anonymous** | Post mode concealing profile identity; documented era exposed only gender | Composer and anonymous post header | 2014 release |
| **Comments** | Public post responses in the 2017 UI | Post action and detail screen | 2017 screenshot |
| **Private response** | Direct response routed to a poster; anonymous poster identity stays concealed | Post detail and conversation creation | Historical descriptions |
| **Erode / erosion** | Expiration behavior altered by post lifespan and community votes | Timer, visual erosion, domain logic, docs | Product name and historical descriptions |
| **Flag** | Community moderation action | Post action row | 2017 screenshot |
| **Likes collected** | Lifetime total shown on profiles | Profile summary | User-supplied profile screenshots |
| **Rodie since** | Member tenure month/year | Profile summary | User-supplied profile screenshots |
| **Connections** | Profile relationship count | Profile connections control | User-supplied validated profile screenshot |
| **Validated** | Confirmed student/profile badge | Profile hero | User-supplied validated profile screenshot |
| **Report Abuse** | Profile-level reporting action | Public profile navigation | User-supplied validated profile screenshot |
| **Start Chat** | Begin a private conversation from a profile | Profile action row | User-supplied profile screenshots |
| **Connect** | Request/create a profile connection | Profile action row | User-supplied profile screenshots |
| **Block** | Block a profile | Profile action row | User-supplied profile screenshots |
| **Anonymous Male / Anonymous Female** | Anonymous identity label including gender | Streamer post identity header | User-supplied anonymous post screenshot |

Unverified labels such as “Like,” “Dislike,” or modern “DM” are intentionally avoided in the core UI. The observed chevrons are presented visually, while documentation calls them positive/negative votes.
