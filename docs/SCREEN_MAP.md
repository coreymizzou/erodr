# Erodr Screen Map

This map separates directly observed screens from screens required by historical behavior but not visually documented by the available repository evidence.

## 1. Classmates feed — directly observed

- **References:** `reference/external/erodr-app-store-2017.png`
- **Layout:** green status/header area; centered title; filter icon; gray selector strip; cyan Popular/Recent/Nearest segments; dense white post stream; fixed five-icon bottom bar.
- **Hierarchy:** author/location/time → text → media → vote/report/response actions.
- **Controls:** feed sort; filters; up/down vote; flag; responses; Stream, messaging/responses, compose, notifications, profile tabs.
- **Destinations:** post response detail, filter sheet, composer, notifications, profile.
- **Unresolved:** exact feed query behind “Nearest”; whether leftmost tab is named Stream or Classmates in this app era; behavior of the speech-bubble tab.

## 2. Splash — required, visually undocumented

- **References:** none supplied.
- **Layout:** temporary reconstruction uses flat Erodr green with a lowercase typographic placeholder wordmark.
- **Control/destination:** automatic transition to login/demo entry.
- **Unresolved:** original logo art, duration, loading indicator, background artwork.

## 3. Login / account entry — required, visually undocumented

- **References:** written evidence for `.edu` validation only.
- **Layout:** period-compatible flat green/white fields and rectangular actions; no modern rounded card.
- **Controls:** demo login, `.edu` email, continue, account creation.
- **Destination:** Classmates feed or college verification.
- **Unresolved:** original copy, exact authentication sequence, logo placement.

## 4. College verification — historically supported, visually undocumented

- **References:** 2014 Erodr press release.
- **Hierarchy:** school email → sent/verification state → validated feeds.
- **Unresolved:** exact form, validation copy, and whether unauthenticated users could enter the Anonymous Ticker immediately in every era.

## 5. Post composer — historically supported, visually undocumented

- **References:** 2013 article (time/distance limits, anonymity, gender filters); 2014 release (photos, anonymous posting).
- **Layout:** flat full-screen composer with text, photo, identity, audience/range, and lifespan controls.
- **Controls:** Identified/Anonymous, Classmates audience, photo attachment, post time/range, publish/cancel.
- **Destination:** newly inserted Classmates or Ticker post.
- **Unresolved:** exact slider appearance, original labels and defaults.

## 6. Post responses — partially supported, visually undocumented

- **References:** screenshot labels `Comments`; written evidence for comments and private responses.
- **Layout:** selected post followed by public responses and a response composer.
- **Controls:** public/private response, identified/anonymous where allowed.
- **Unresolved:** era-specific term (`Comments` vs `Responses`), anonymous response rules, vote controls on responses.

## 7. Private response / conversation — historically supported, visually undocumented

- **References:** 2014 release and archived app description.
- **Behavior:** a responder can reveal their profile to an anonymous poster without learning the poster’s identity; identity is retained internally for routing.
- **Unresolved:** alias format, retention relationship to the expiring source post, photo message UI.

## 8. Conversations list and detail — historically supported, visually undocumented

- **References:** written evidence for private photo messaging/messages.
- **Layout:** dense white rows and gray dividers consistent with the observed shell.
- **Controls:** open conversation, send text, receive realtime messages.

## 9. Profile — historically supported, visually undocumented

- **References:** written evidence for name/photo/school and profile access from attributed activity.
- **Hierarchy:** profile image, name, Mizzou/class year/bio, identified posts only.
- **Privacy:** never associate anonymous activity with the public profile.
- **Unresolved:** photo gallery layout, edit controls, exact fields and metrics.

## 10. Anonymous Ticker — historically supported, visually undocumented

- **References:** 2014 press release and archived app description.
- **Behavior:** continuous cross-campus anonymous posts; available before `.edu` validation in the documented 2014 flow.
- **Distinction:** anonymous nationwide immediacy, not the ranked identified National Feed.

## 11. National Feed — historically supported, visually undocumented

- **References:** 2014 press release.
- **Behavior:** best attributed posts from validated students around the country; validated-student access.

## 12. Notifications and settings — icon evidence / required support

- **References:** bell with unread dot and filter/settings-like header icon in the 2017 screenshot.
- **Unresolved:** notification categories, settings navigation, exact rows and terminology.
